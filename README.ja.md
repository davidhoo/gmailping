# GmailPing

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [Español](README.es.md)

GmailPing は、複数の Gmail 受信トレイの未読メール数を Mac のメニューバーにまとめて表示します。新着通知をクリックすると、そのメールが届いた受信トレイがデフォルトのブラウザで開きます。

## インストールして Gmail に接続する

1. [リリースページ](https://github.com/davidhoo/gmailping/releases)からユニバーサル版の `.dmg` をダウンロードします。macOS 13 以降を搭載した Apple シリコンおよび Intel Mac に対応しています。`.dmg.zip` を選んだ場合は先に展開してください。バージョン 1.1.0 はアドホック署名を使用しており、Apple の公証は受けていません。
2. ディスクイメージを開き、**GmailPing** を「アプリケーション」にドラッグして、そこから起動します。メニューバーに封筒のアイコンが表示されます。
3. 封筒をクリックして設定を開きます。アプリの表示言語は簡体字中国語です。**账号**（アカウント）で **添加 Google 账号...**（Google アカウントを追加）を選び、ブラウザで Gmail アカウントを選択してアクセスを許可します。他の受信トレイも同じ手順で追加できます。
4. 新着通知を受け取るには、macOS の確認画面で通知を許可します。通知音やチェック間隔は **偏好设置**（設定）で変更できます。

1.1.0 以降は GitHub Releases で毎日更新を確認し、新版のインストールを案内します。封筒の右クリックメニューから「检查应用更新…」で今すぐ確認でき、「自动检查应用更新」で自動確認を切り替えられます。旧版からは初回のみ手動で更新してください。

## 未読メールのある受信トレイを開く

封筒をクリックすると、未読メールがあるアカウントが 1 つなら、その受信トレイが直接開きます。複数ある場合は、アドレスと未読数の一覧から選べます。未読メールが確認されていない場合は、デフォルトの受信トレイが開きます。封筒を右クリックすると、各アカウントの最終チェック時刻の確認、手動チェック、デフォルトアカウントの変更ができます。

1 回のチェックで同じ受信トレイに複数の新着メールが見つかると、通知は 1 件にまとまります。以前のメールを未読に戻しても、未読数が更新されるだけで新着通知は届きません。

受信トレイを開くと、そのアカウントだけを 5 秒後に確認し、その後は 10 秒間隔で最長 1 分間確認します。未読がゼロになると通常の間隔に戻ります。手動モードではこの確認を行いません。

## プライバシーとサポート

Mac から Google に直接接続してメールの件数、メッセージ ID、ラベルを確認します。本文や添付ファイルは Gmail に残り、各アカウントの認証トークンは macOS のキーチェーンに保存されます。接続を解除するには「账号」でアカウントを削除します。Google アカウント側でもアクセスを取り消せます。[プライバシーポリシー（中国語）](https://davidhoo.github.io/gmailping/privacy/) · [Google アカウントの接続管理](https://myaccount.google.com/connections)
