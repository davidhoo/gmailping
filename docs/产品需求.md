# GmailPing V1 产品需求

设计稿 · 2026-11-19

GmailPing 服务于同时关注个人邮箱和工作邮箱的 Mac 用户。用户平时只看一个菜单栏数字，收到提醒时可以一步进入对应 Gmail 网页。应用在本机运行，独立于浏览器进程和 Apple Mail。邮件阅读、回复、搜索、发送及附件操作均在 Gmail 网页完成。

## 图标与外观

“与 Gmail 官方 icon 一致”在本稿中指使用 Google 发布的 Gmail 彩色原图，保留颜色、比例、透明留白和形状。以 Google 品牌资源中心的 Gmail 条目为视觉参照。原稿的单色模板要求适用于独立的菜单栏符号。对官方彩色素材采用原色渲染。 [Gmail 品牌资源入口](https://about.google/brand-resource-center/products-and-services/)

| 位置 | 设计与交付条件 |
| --- | --- |
| 菜单栏 | 首选官方 Gmail 图标，数字以系统文字排在右侧。此处同时承担第三方应用常驻入口，公开版采用该素材前须确认这一用途。可分发的备选为独立信封模板图标，随系统外观着色。 |
| Finder、系统登录项、通知中心 | 使用 Google 当前发布的 Gmail 彩色图标，保留原图颜色、比例和透明背景。应用包内置多分辨率 ICNS，系统通知沿用应用图标。[官方图标原稿](https://www.gstatic.com/images/branding/productlogos/gmail_2026/v2/web/192px.svg) |
| 设置与菜单的「打开 Gmail」 | 这里指向 Google 服务，优先使用符合该用途指引的官方原图与文字。授权登录控件采用 Google 登录按钮规范。 |

GmailPing 作为当前项目名。公开发行时核对名称和各图标用途。获取到素材与取得第三方应用标识使用许可是两个独立事项。浅色、深色、选中背景均要求图标可辨，状态变化通过文字和辅助功能描述表达。[Google 品牌通则](https://about.google/brand-resource-center/guidance/) · [Google 登录按钮规范](https://developers.google.com/identity/branding-guidelines)

## 菜单栏与账号

| 用户操作或状态 | V1 行为 |
| --- | --- |
| 首次手动启动 | 进入菜单栏，提供一次轻量的添加账号引导。可取消，之后从右键菜单重开。登录系统后的自动启动保持安静。 |
| 左键单击 | 按最近已知的收件箱未读数判断。仅一个账号有未读时直接打开该账号。多个账号有未读时，下拉菜单列出这些账号的邮箱地址及各自未读数，点选一行即打开对应收件箱。没有已知未读时打开默认账号。零账号时打开添加账号界面。 |
| 右键或 Control-单击 | 显示合计、各邮箱地址、各自未读数、上次成功检查时间和异常原因。提供「立即检查全部」「打开默认 Gmail」「偏好设置」「退出 GmailPing」。各账号可单独打开或检查。 |
| 添加账号 | 从设置或无账号菜单发起 Google 授权。每个账号首次连接时单独建立基线。重复添加同一 Google 身份只更新原账号授权，取消不产生空账号。 |
| 设为默认 | 首个添加成功的账号成为默认。更改后，「打开默认 Gmail」及没有已知未读时的左键点击均打开新默认账号。其他账号仍持续监测，现有通知仍指向原账号。 |
| 重新授权 | 只修复所选账号。浏览器中选错账号时提示重新选择，保留原有绑定和其他账号状态。 |
| 移除账号／退出登录 | 明示目标地址。确认后停止该账号检测、清除其本地凭据、状态和通知，立即更新合计。移除默认账号后按添加顺序选取首个剩余账号。移除最后一个后保留菜单栏及添加入口。 |
| 关闭设置／退出应用 | 关闭窗口后继续监测。退出应用时结束所有检查。平时无主窗口、无 Dock 图标，后台事件不抢焦点。 |

菜单栏的数字为所有已连接账号最近一次成功读取的 **INBOX 未读邮件数之和**，按邮件计数。真实合计 99 显示 99，100 起显示 99+，右键菜单始终可看完整数值。已同步且合计为零时默认只显示图标。首次同步前显示「等待同步」。部分账号离线或待重新授权时保留已知数值，菜单栏提示文本标出「部分账号待更新」，菜单和辅助功能描述标明哪些账号数据过期、有几个账号尚无数据。全部未知时只显示图标。移除账号立即扣除它的贡献。

## 邮件与通知

| 邮箱变化 | 未读计数 | 系统通知 |
| --- | --- | --- |
| 新增账号，邮箱已有未读 | 立即读取该账号数量 | 静默建立基线，包括第二个及后续账号 |
| 同一检查中，A 收到 3 封、B 收到 1 封 | 分别更新并汇总 | 两条通知，A 的一条写「收到 3 封新邮件」，B 的一条写「收到 1 封新邮件」 |
| 一封新邮件在检查前已被手机读过，仍在收件箱 | 使用 Gmail 当前未读数 | 仍属于新到达。新邮件提醒与未读数独立 |
| 把旧邮件标为未读、已读，或把已有邮件移回收件箱 | 下次检查反映 Gmail 结果 | 无新邮件通知 |
| 检查时仅在归档、已发送、垃圾邮件或垃圾箱中 | 不计入收件箱 | 无新邮件通知 |
| 增量位置过期或丢失 | 重新读取当前数量 | 该账号静默重建基线。其他账号照常通知 |

通知标题为「收到新邮件」，副标题显示收件邮箱，正文只含封数。以同一账号同一次检查合并，点击跳转到该邮箱的收件箱。默认浏览器若缺少该账号的登录会话，由 Google 引导选择账号或登录。系统专注模式、权限及声音设置优先。关闭应用通知或系统拒绝授权时，数字继续更新，重新开启后从后续新增邮件开始提醒。

## 设置与同步时机

| 设置 | 默认 | 生效范围 |
| --- | --- | --- |
| 登录时自动启动 | 开启 | 整个应用。设置中展示 macOS 实际登记／待批准状态 |
| 检查间隔 | 60 秒 | 全部账号，可选 30 秒、60 秒、2 分钟、5 分钟、手动 |
| 显示未读数量 | 开启 | 菜单栏。关闭后菜单内仍有明细 |
| 未读为零时隐藏数字 | 开启 | 已开启显示数量时生效 |
| 新邮件系统通知／通知声音 | 均开启 | 全部账号。关闭通知时声音选项随之停用 |
| 系统登录时提醒已有未读 | 关闭 | 登录项启动且原有账号首次成功同步后，各账号至多一次未读摘要。摘要明示「收件箱有 N 封未读邮件」。若同轮有新邮件，优先发新邮件通知。零未读、首次建基线和重建基线均静默。 |
| 默认打开的账号 | 首个添加成功的账号 | 可在账号列表更改 |

自动模式在启动、唤醒、网络恢复时检查，重复事件合并。手动模式按原稿「只在用户主动操作时检查」处理。添加或修复授权时完成必要同步，此后由「立即检查」触发。手动模式不会因唤醒、联网或登录项启动而自动查询或提醒。临时错误在自动模式下退避重试。菜单保留上次成功时间。

## 平台、隐私与范围

- macOS 13+，原生支持 Apple Silicon，尽量兼容 Intel。适配浅色和深色。以空闲 CPU 接近零、常驻内存尽可能低于 50 MB 为优化目标，按实测列出账号数和机器配置。
- 使用 OAuth 与系统钥匙串。只查询 Google 官方接口取得身份和必要的邮件元数据。无需 Gmail 密码、IMAP 或常开浏览器。本机不保存正文、主题、发件人、附件或敏感日志，邮件数据不上传至开发者服务器。
- V1 包含多账号、逐账号及汇总计数、默认账号与通知定向。发件人或主题预览、按邮件直达、通知过滤、自定义样式、暂停提醒留待后续。云端推送、邮件客户端功能、非 Gmail 邮箱和移动端均在本期范围外。
