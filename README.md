# GmailPing

GmailPing 是为 macOS 13 及更新版本设计的原生菜单栏工具。一个图标汇总多个 Gmail 收件箱的未读邮件数。点击图标打开默认邮箱，点击新邮件通知打开收到邮件的邮箱。
